# Michel et al. 2017, S. cerevisiae SATAY

eLife 6:e23570. ArrayExpress E-MTAB-4885 (ENA ERP016475): MiniDs (Ac/Ds) libraries, single-end MiSeq. All seven libraries: WildType1 and WildType2 (parents); WT + rapamycin; and the mutants dpl1Δ, dpl1Δ psd2Δ, VPS13(D716H) and mmm1Δ VPS13(D716H). Rapamycin and the mutants are `treated` (their `condition` names the treatment or genotype) so they pair with the WT libraries in condition comparisons, and the mutant sets serve genetic-interaction and multi-condition benchmarks. Design `ac_ds/satay_restriction`.

The donor plasmid carries ADE2, URA3, CYC1 and GAL1-10 sequence; reads from it pile up on those genomic loci and must be masked in analyses.

Table 1 of the paper also lists a YEN1on library; it was not deposited (E-MTAB-4885 holds the seven libraries above) and would have to be requested from the authors. Wild-type 1 and VPS13(D716H) were sequenced on two MiSeq runs each; ENA serves each as one run.
