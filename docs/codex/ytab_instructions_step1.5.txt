Important:

- Python remains the backend.
- Minimum threads remain 2.
- Do not modify pipeline algorithms.
- Do not run alignment.
- Do not delete outputs.
- Do not use qsub/HPC paths.

2. scripts/setup_ytab_local.sh

Create a setup script that:
- checks whether mamba or conda exists
- prefers mamba if available
- creates or updates the ytab-local environment from environment.local.yml
- prints clear next commands:
    mamba activate ytab-local
    python scripts/local/ytab_check_local_env.py
    python scripts/local/ytab_smoke_reference_discovery.py
    Rscript app/shiny/run_app.R
- does not hard-code user-specific paths
- works from repo root
- exits with clear messages if neither conda nor mamba is available
- tells user to install Miniforge if conda/mamba is missing

4. scripts/local/ytab_check_resources.py

Create a resource checker that:
- lists species under resources/species/
- for each species, reports:
    FASTA found yes/no
    GFF found yes/no
    feature table found yes/no
    gffutils DB found yes/no
    Bowtie2 index complete yes/no
    centromere BED found yes/no
    tRNA BED found yes/no
    orthology file found yes/no
- uses src/ytab/pipeline/reference_registry.py
- exits zero if at least one species is runnable
- exits nonzero if no species has minimum required reference files
- prints a clear message if glabrata/albicans resources are missing from the local checkout
